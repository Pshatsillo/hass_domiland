# Domiland for Home Assistant

Интеграция Home Assistant для управления счётчиками и данными из приложения **Домиленд+**.

## Возможности

- 📊 **Сенсоры счётчиков**: текущее показание, предыдущее, расход
- 📅 **Сенсоры дат**: дата последней передачи, дата поверки
- 📜 **История показаний**: последние 12 записей в атрибутах
- 📈 **Статистика**: импорт истории в long-term statistics HA
- ✏️ **Ввод и отправка показаний**: Number с debounce и валидацией
- 🔐 **OAuth2-авторизация**: через Яндекс, с автоматическим обновлением токена
- 🔄 **Reauth**: автоматическое восстановление при истечении токена

## Установка через HACS

1. Откройте **HACS → Integrations**.
2. Нажмите **⋮ → Custom repositories**.
3. Добавьте URL: `https://github.com/Pshatsillo/hass_domiland`, категория — **Integration**.
4. Найдите **Domiland** в HACS → **Download**.
5. Перезапустите Home Assistant.

## Настройка

### 1. Создайте приложение в Яндекс OAuth

1. Откройте https://oauth.yandex.ru/client/new
2. Заполните:
   - **Название**: `Home Assistant Domiland`
   - **Redirect URI**: `https://my.home-assistant.io/redirect/oauth` (или `https://<ваш-домен>/auth/external/callback`)
3. Скопируйте **Client ID** и **Client Secret**.

### 2. Добавьте Application Credentials в HA

1. **Настройки → Устройства и службы → Application Credentials**.
2. **Добавить**: `Domiland` → введите `Client ID` и `Client Secret`.

### 3. Добавьте интеграцию

1. **Настройки → Устройства и службы → Добавить интеграцию → Domiland**.
2. HA перенаправит в Яндекс → подтвердите доступ.
3. Интеграция создастся автоматически.

## Использование

### Передача показаний

**Вручную или через автоматизацию:** измените значение в Number `Водоотведение — ввод показания` → через 10 секунд отправится автоматически.
