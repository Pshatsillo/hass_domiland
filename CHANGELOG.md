# Changelog

## [1.0.0] - 2026-09-18

### Added
- Первый публичный релиз
- OAuth2-авторизация через Яндекс
- Автоматическое обновление токена Домиленда при 401
- Reauth-флоу при истечении токена
- Сенсоры счётчиков: показание, предыдущее, расход
- Сенсор даты последней передачи
- Сенсор даты поверки
- Сенсор истории показаний (последние 12 записей)
- Импорт истории в статистику Home Assistant
- Number для ввода показаний с debounce (10 секунд)
- Валидация: новое показание не меньше текущего
- Сенсоры счетов и заявок
